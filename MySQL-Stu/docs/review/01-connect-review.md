# 第 1 章复习：连接 MySQL 与进入数据库

## 自测题

1. `mysql -h 127.0.0.1 -P 3306 -u root -p` 中每个参数分别表示什么？
2. MySQL、数据库、数据表三者有什么关系？
3. 连接成功后，如何查看当前有哪些数据库？
4. 如何切换到 `mysql_study` 数据库？
5. 如果连接失败，你会先排查哪三类问题？

## 面试题版答案

1. `-h` 是主机地址，`-P` 是端口，`-u` 是用户名，`-p` 表示输入密码。这几个参数共同决定了客户端如何连接到指定的 MySQL 实例。
2. MySQL 是数据库管理系统，数据库是系统里的一个数据容器，数据表是数据库中的具体结构，真正的数据按行按列保存在表里。
3. 可以使用 `SHOW DATABASES;` 查看当前实例中的数据库列表。
4. 使用 `USE mysql_study;` 切换到目标数据库。
5. 我会先检查服务是否启动、主机和端口是否正确、用户名密码是否正确。如果这些都没问题，再看权限或实例地址是否配错。
