# 第 10 章复习：EXPLAIN 与查询优化入门

## 自测题

1. `EXPLAIN` 的主要用途是什么？
2. 初学阶段看执行计划时，先重点看哪些字段？
3. 为什么 `SELECT *` 不一定是好习惯？
4. 为什么对字段做函数处理可能影响索引使用？
5. 查询优化的目标到底是什么？

## 面试题版答案

1. `EXPLAIN` 的主要用途是观察数据库打算如何执行一条 SQL，帮助我们理解执行计划和潜在性能问题。
2. 初学阶段建议先重点看 `type`、`key`、`rows`、`Extra` 这些字段。
3. 因为它会把所有列都取出来，在真实项目里可能增加不必要的 I/O 和网络传输开销。
4. 因为这类写法可能让数据库无法直接利用原字段上的索引去快速定位数据，从而退化为更重的扫描方式。
5. 查询优化的目标不是把 SQL 写得更花哨，而是减少无效扫描、降低开销、让数据库更高效地返回结果。
