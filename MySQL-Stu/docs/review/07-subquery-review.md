# 第 7 章复习：子查询

## 自测题

1. 什么是子查询？
2. 子查询常见可以放在哪些位置？
3. 子查询和 `JOIN` 的思路差别是什么？
4. 什么叫“先得到中间结果，再继续过滤”？
5. 什么是关联子查询？

## 面试题版答案

1. 子查询就是在一条 SQL 中再嵌一条 SQL，让内层查询结果为外层查询服务。
2. 常见位置有 `WHERE`、`FROM`，有时也会出现在 `SELECT` 中。
3. `JOIN` 更像把多张表拼接起来取数，子查询更像先算出一个中间结果，再基于它继续查询。
4. 例如先统计每个学生的平均分，再从这个统计结果里筛选平均分大于某个值的学生，这就是典型的两段式思路。
5. 关联子查询是指内层查询会引用外层查询当前行的字段，因此外层每一行都可能触发一次内层比较。
