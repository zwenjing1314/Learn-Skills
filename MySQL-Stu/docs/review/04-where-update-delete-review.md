# 第 4 章复习：条件查询、更新与删除

## 自测题

1. `WHERE` 在查询、更新、删除里分别起什么作用？
2. 为什么 `UPDATE` 和 `DELETE` 特别强调要带条件？
3. `ORDER BY` 和 `LIMIT` 分别解决什么问题？
4. `BETWEEN` 和 `LIKE` 分别适合什么场景？
5. 为什么建议先写 `SELECT` 再写 `UPDATE` 或 `DELETE`？

## 面试题版答案

1. `WHERE` 的本质是限定作用范围。查询时是筛选数据，更新时是限定修改哪些行，删除时是限定删除哪些行。
2. 因为如果没有 `WHERE`，这两类语句可能直接作用于整张表，风险很高。
3. `ORDER BY` 用于排序结果，`LIMIT` 用于限制返回条数，常用于分页或只看前几条结果的场景。
4. `BETWEEN` 适合区间查询，`LIKE` 适合模糊匹配，例如按关键字查姓名。
5. 因为先写 `SELECT` 可以先验证条件是否命中了你真正想操作的数据，这是一种很重要的安全习惯。
