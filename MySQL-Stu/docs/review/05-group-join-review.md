# 第 5 章复习：分组统计与多表查询

## 自测题

1. `GROUP BY` 的作用是什么？
2. `COUNT`、`AVG`、`MAX` 常和什么语法配合使用？
3. 写多表查询前，最应该先想清楚哪三件事？
4. 为什么 `scores` 表是多表查询的关键？
5. `JOIN` 和普通单表查询最大的不同是什么？

## 面试题版答案

1. `GROUP BY` 用于先按某个字段分组，再对每组做统计。
2. 它们通常和 `GROUP BY` 一起使用，用来做数量、平均值、最大值等聚合统计。
3. 要先想清楚字段分别在哪张表、表和表靠什么字段关联、最后要的是明细结果还是统计结果。
4. 因为它把学生和课程关联起来了，既有学生维度，也有课程维度，所以很多联表查询都要经过它。
5. 单表查询只在一张表里取数据，`JOIN` 是把多张表通过关联条件组合起来后再取结果。
