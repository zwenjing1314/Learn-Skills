# 第 3 章复习：新增数据与基础查询

## 自测题

1. `INSERT INTO ... VALUES ...` 的核心作用是什么？
2. 插入数据时，字段顺序和数值顺序有什么要求？
3. `SELECT *` 和查询指定列有什么区别？
4. 别名 `AS` 的作用是什么？
5. 为什么建议每次插入后都跟一条查询语句？

## 面试题版答案

1. 它的作用是向表中新增一条或多条记录，是最基础的数据写入操作。
2. 字段顺序和数值顺序必须一一对应，否则容易出现类型错误或把数据写错列。
3. `SELECT *` 会查询所有列，适合快速查看；查询指定列更精确，也更接近真实项目里的常见写法。
4. `AS` 用来给结果列起别名，让返回结果更易读，尤其适合报表或教学场景。
5. 因为这样可以立刻验证写入是否成功，也能帮助建立“写入数据”和“读取结果”之间的联系。
