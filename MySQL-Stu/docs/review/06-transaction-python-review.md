# 第 6 章复习：事务基础与 Python 操作 MySQL

## 自测题

1. 事务要解决什么问题？
2. `COMMIT` 和 `ROLLBACK` 分别表示什么？
3. 为什么 Python 执行插入、更新、删除后通常要 `commit()`？
4. Python 操作数据库的大致流程是什么？
5. 在什么情况下你会考虑回滚事务？

## 面试题版答案

1. 事务用于保证一组相关操作的一致性，避免执行到一半失败后导致数据处于不完整状态。
2. `COMMIT` 表示提交事务并永久生效，`ROLLBACK` 表示撤销事务中的修改并回到事务开始前的状态。
3. 因为很多数据库驱动默认不会自动把修改立即落盘，只有提交事务后，数据变更才真正生效。
4. 一般是建立连接、创建游标、执行 SQL、提交事务、关闭游标和连接。
5. 当一组操作中间有任何一步失败，或者结果不符合预期时，就应该考虑回滚，保证整体一致性。
