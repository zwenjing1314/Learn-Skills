# 第 9 章复习：索引

## 自测题

1. 索引的核心作用是什么？
2. 为什么索引不是越多越好？
3. 哪类字段更适合考虑建立索引？
4. 如何查看一张表上的索引？
5. 为什么数据量很小时，索引效果可能不明显？

## 面试题版答案

1. 索引的核心作用是帮助数据库更快定位数据，减少不必要的扫描。
2. 因为索引会占空间，也会增加插入、更新、删除时的维护成本，所以不能盲目增加。
3. 经常出现在过滤条件、排序条件、联表条件中的字段，通常更适合优先考虑索引。
4. 可以使用 `SHOW INDEX FROM 表名;` 查看一张表上的索引情况。
5. 因为数据量小时，全表扫描成本本来就低，所以执行计划不一定会表现出非常明显的差异。
