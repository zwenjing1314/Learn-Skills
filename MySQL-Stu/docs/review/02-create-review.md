# 第 2 章复习：创建数据库、数据表和初始化数据

## 自测题

1. 为什么通常要先建数据库，再建数据表？
2. `students`、`courses`、`scores` 三张表分别存什么？
3. 为什么 `scores` 表适合放外键？
4. 为什么初始化时要插入测试数据？
5. 如果表已经存在，重复执行建表脚本前应该注意什么？

## 面试题版答案

1. 因为数据表必须创建在某个数据库之中，所以要先有数据库容器，再在里面创建表结构。
2. `students` 存学生基本信息，`courses` 存课程信息，`scores` 存学生和课程之间的成绩关系。
3. 因为成绩记录天然依赖学生和课程，外键能保证成绩关联的学生和课程是真实存在的，避免脏数据。
4. 没有测试数据，后面的查询、联表、统计和事务演示都无法直观看到结果，所以初始化数据是学习链路的一部分。
5. 要注意重复执行时是否会报表已存在的错误，通常会配合 `DROP TABLE IF EXISTS` 或者先清理旧环境。
