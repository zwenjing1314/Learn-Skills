# 第 8 章复习：视图

## 自测题

1. 什么是视图？
2. 视图和数据表有什么本质区别？
3. 为什么视图适合封装复杂查询？
4. 查询视图时体验上为什么像在查表？
5. 使用视图时需要注意什么依赖关系？

## 面试题版答案

1. 视图可以理解为保存下来的查询逻辑入口，方便后续重复使用。
2. 数据表主要存储真实数据，视图主要保存查询定义，通常不独立保存一份完整的数据副本。
3. 因为把复杂的联表逻辑封装成一个统一名字后，后续查询者只需要面向这个视图继续筛选或统计。
4. 因为数据库允许像查询表一样查询视图，所以使用方式上很接近，但底层仍然依赖原始查询逻辑。
5. 要注意视图依赖底层表结构，如果底层字段名或表结构变化，视图也可能失效或需要调整。
