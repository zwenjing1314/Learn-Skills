# 第 9 章：索引

## 本章目标

这一章带你建立对索引的第一层正确认识。

你会学习：

- 索引是为了解决什么问题
- 常见索引创建方式
- 为什么索引不是越多越好
- 如何初步观察索引是否可能生效

## 先理解索引在解决什么问题

当表里的数据很多时，如果每次查询都从头扫到尾，速度就会越来越慢。

索引的核心作用，是帮助数据库更快地定位数据。

你可以先把它理解成书的目录：

- 没有目录时，只能一页一页翻
- 有了目录后，可以更快找到目标内容

## 为什么索引不是越多越好

因为索引虽然能帮助查询，但也会带来代价：

- 占用更多存储空间
- 插入、更新、删除时需要额外维护索引

所以索引不是加得越多越强，而是要加在“经常查询、经常过滤、经常排序”的字段上。

## 初学阶段最该掌握什么

你现阶段不需要深入 B+ 树底层细节，但需要先知道：

- 如何创建普通索引
- 如何删除索引
- 如何用 `SHOW INDEX` 查看索引
- 如何用 `EXPLAIN` 初步观察查询计划

这一章学完后，你应该能理解：
