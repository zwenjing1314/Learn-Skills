# 第 8 章：视图

## 本章目标

这一章帮助你认识一个很实用但初学者常忽略的主题：视图。

你会学习：

- 什么是视图
- 什么时候适合使用视图
- 为什么视图适合封装复杂查询

## 什么是视图

你可以先把视图理解成“保存下来的查询结果入口”。

它不是把数据重新复制一份，而是把一段查询逻辑保存成一个可复用的名字。

例如原本你每次都要写：

- 学生姓名
- 课程名称
- 分数
- 考试日期

这类三表联查很长，重复写会很累。于是我们可以把它做成一个视图。

以后再查时，就可以像查表一样去查这个视图。

## 视图适合哪些场景

- 经常重复使用的复杂查询
- 想给初学者一个更简单的查询入口
- 想把底层多表结构封装起来

## 使用视图时需要注意什么

- 视图更偏向“简化查询”，不是“替代建表”
- 视图会依赖底层表结构
- 如果底层字段发生变化，视图也可能受影响

## 章节小结

这一章学完后，你应该能理解：

- 视图本质上保存的是查询逻辑
- 视图可以简化复杂 SQL 的重复编写
- 使用视图查询时，体验上很像查询一张表
