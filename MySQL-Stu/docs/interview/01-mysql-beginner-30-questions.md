## 1. 什么是 MySQL？

### 参考答案

MySQL 是一种关系型数据库管理系统，用来存储、管理和查询结构化数据。它使用 SQL 语言来操作数据，在 Web 开发和业务系统中很常见。

### 必背点

- 关系型数据库管理系统
- 用 SQL 操作数据
- 常用于业务系统和网站开发

## 2. 数据库、数据表、字段、记录分别是什么？

### 参考答案

数据库是存放数据的容器，数据表是数据库中的具体表结构，字段就是表中的列，记录就是表中的一行数据。

### 必背点

- 数据库像大容器
- 表像二维结构
- 字段是列
- 记录是行

## 3. 什么是 SQL？

### 参考答案

SQL 是结构化查询语言，用来和数据库交互。它不仅能查询数据，还能新增、修改、删除数据，也能创建数据库和表结构。

### 必背点

- SQL 是操作数据库的语言
- 不只是查，还能增删改和建表

## 4. 什么是主键？

### 参考答案

主键是用来唯一标识一条记录的字段，要求值不能重复，也不能为 `NULL`。在表设计中，主键常用于定位一条数据。

### 必背点

- 唯一标识一条记录
- 不能重复
- 不能为 `NULL`

## 5. 什么是外键？

### 参考答案

外键用于建立表和表之间的关联关系。它通常引用另一张表的主键，用来保证关联数据的有效性和一致性。

### 必背点

- 建立表之间的关系
- 通常引用另一张表的主键
- 保证数据一致性

## 6. `DELETE`、`DROP`、`TRUNCATE` 有什么区别？

### 参考答案

`DELETE` 是删除表中的数据，可以配合 `WHERE` 删除部分数据；`TRUNCATE` 是清空整张表的数据；`DROP` 是直接删除整张表或整个数据库结构。它们影响范围和风险级别都不同。

### 必背点

- `DELETE` 删数据
- `TRUNCATE` 清空表数据
- `DROP` 删表或删库

## 7. `WHERE` 的作用是什么？

### 参考答案

`WHERE` 用于限定 SQL 的作用范围，可以出现在查询、更新、删除语句中。它的本质是告诉数据库“只处理符合条件的数据”。

### 必背点

- 限定作用范围
- 查询、更新、删除都能用
- 很重要，能避免误操作整张表

## 8. `ORDER BY` 和 `GROUP BY` 有什么区别？

### 参考答案

`ORDER BY` 用于对结果排序，`GROUP BY` 用于对结果分组统计。前者关注顺序，后者关注聚合分析。

### 必背点

- `ORDER BY` 是排序
- `GROUP BY` 是分组
- 一个看顺序，一个做统计

## 9. 什么是 `JOIN`？

### 参考答案

`JOIN` 是多表查询时用来关联数据的语法。它通过表之间的关联字段，把多张表的数据组合到一起，得到更完整的查询结果。

### 必背点

- 多表关联查询
- 通过关联字段把结果拼起来

## 10. `INNER JOIN` 是什么？

### 参考答案

`INNER JOIN` 只返回两张表中能够成功匹配上的数据。如果某一边没有对应记录，就不会出现在结果里。

### 必背点

- 只返回匹配成功的数据
- 两边都得有对应记录

## 11. 什么是事务？

### 参考答案

事务是一组 SQL 操作的集合，这组操作要么全部成功，要么全部失败。它主要用来保证数据的一致性。

### 必背点

- 一组操作作为整体执行
- 要么都成功，要么都失败
- 核心是数据一致性

## 12. `COMMIT` 和 `ROLLBACK` 的区别是什么？

### 参考答案

`COMMIT` 表示提交事务，让本次修改正式生效；`ROLLBACK` 表示回滚事务，撤销本次事务中的修改。

### 必背点

- `COMMIT` 提交
- `ROLLBACK` 回滚

## 13. 什么是索引？

### 参考答案

索引是帮助数据库更快定位数据的一种结构。它的主要作用是提高查询效率，但也会增加存储和维护成本。

### 必背点

- 提高查询效率
- 不是免费能力
- 会增加维护成本

## 14. 为什么索引不是越多越好？

### 参考答案

因为索引会占用空间，而且插入、更新、删除数据时都需要同步维护索引。索引太多会影响写入性能，所以应该建在真正高频查询的字段上。

### 必背点

- 占空间
- 影响写入性能
- 要建在常用查询字段上

## 15. 什么情况下适合考虑建立索引？

### 参考答案

通常在经常出现在 `WHERE`、`ORDER BY`、`JOIN` 条件中的字段上考虑建立索引，因为这些场景最容易从索引中获益。

### 必背点

- 常用过滤字段
- 常用排序字段
- 常用联表字段

## 16. 什么是视图？

### 参考答案

视图可以理解为保存下来的查询逻辑。它本身更偏向简化复杂查询，让后续查询者可以像查表一样使用一段固定的 SQL 结果入口。

### 必背点

- 保存查询逻辑
- 简化复杂查询
- 用法像表，底层依赖原表

## 17. 什么是子查询？

### 参考答案

子查询就是在一条 SQL 里面再嵌一条 SQL，用内层查询结果去支持外层查询。常见于 `WHERE`、`FROM` 等位置。

### 必背点

- 查询中的查询
- 常放在 `WHERE` 或 `FROM`

## 18. `SELECT *` 为什么不总是推荐？

### 参考答案

因为 `SELECT *` 会把所有列都查出来，可能带来不必要的数据传输和处理开销。在真实项目中，如果只需要部分字段，通常更推荐明确写出需要的列。

### 必背点

- 会查出所有列
- 可能有额外开销
- 更推荐按需查询

## 19. `COUNT(*)` 是做什么的？

### 参考答案

`COUNT(*)` 用于统计结果集中的记录总数。它常和 `GROUP BY` 一起使用，用来统计每组有多少条数据。

### 必背点

- 统计行数
- 常配合 `GROUP BY`

## 20. 什么是唯一约束？

### 参考答案

唯一约束用于保证某个字段中的值不能重复，但和主键不同的是，一张表可以有多个唯一约束，而主键通常只有一个。

### 必背点

- 限制字段值不能重复
- 一张表可以有多个唯一约束

## 21. `NULL` 是什么？

### 参考答案

`NULL` 表示没有值、未知值或缺失值。它不等于空字符串，也不等于 0，在 SQL 判断中需要特别注意。

### 必背点

- 表示未知或缺失
- 不等于空字符串
- 不等于 0

## 22. 为什么判断 `NULL` 不能直接用 `= NULL`？

### 参考答案

因为 `NULL` 不是一个普通值，而是表示“未知”。在 SQL 中判断 `NULL` 通常要用 `IS NULL` 或 `IS NOT NULL`。

### 必背点

- 不能直接 `= NULL`
- 要用 `IS NULL`

## 23. 什么是自增主键？

### 参考答案

自增主键是指主键值随着新记录插入自动递增生成，常用于整数类型主键，能减少手动维护主键值的麻烦。

### 必背点

- 自动递增
- 常用于整数主键

## 24. 为什么多表设计比把所有字段放一张表更常见？

### 参考答案

因为合理拆表能减少数据冗余、提高结构清晰度，也更符合业务关系设计。多表设计虽然查询会复杂一些，但更利于维护和扩展。

### 必背点

- 减少冗余
- 结构更清晰
- 更利于维护和扩展

## 25. 什么是冗余数据？

### 参考答案

冗余数据是指重复保存的相同信息。冗余过多会让数据维护变得困难，也容易在更新时出现不一致问题。

### 必背点

- 重复数据
- 容易带来维护问题和不一致

## 26. 什么是分页查询？

### 参考答案

分页查询是指分批获取数据，而不是一次查出全部结果。MySQL 里常用 `LIMIT` 来实现分页。

### 必背点

- 分批取数据
- 常用 `LIMIT`

## 27. 什么是 `EXPLAIN`？

### 参考答案

`EXPLAIN` 是查看 SQL 执行计划的工具。它可以帮助我们了解数据库打算如何执行一条查询语句，从而辅助判断是否有优化空间。

### 必背点

- 查看执行计划
- 用于分析 SQL 是否合理

## 28. 查询优化的核心目标是什么？

### 参考答案

查询优化的核心目标是让数据库以更低成本拿到正确结果，例如减少全表扫描、减少不必要的数据读取、提高索引利用率。

### 必背点

- 更低成本拿到正确结果
- 减少无效扫描
- 提高索引利用率

## 29. 什么是关系型数据库？

### 参考答案

关系型数据库是以表结构来组织数据，并通过表与表之间的关系来表示业务关联的一类数据库。MySQL 就属于关系型数据库。

### 必背点

- 用表来组织数据
- 强调表之间的关系
- MySQL 属于关系型数据库

### 必背点
